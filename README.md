This project was prepared as a master's thesis at XJTU. The final report includes all relevant information of the project methodology and results at 'RSJ_PRC_论文'. 
'PV_curve' and 'exp_results3' process various data from the 'data' folder to produce the plots and error figures.
'newPVmethod_1' is the complete simulation of the system initialized by 'PV_sim_init'.
The 'Controller' and 'controller_init' files were used together to test just the controller for the boost converter. 
The two appx photos are of the hardware experiment setup.
